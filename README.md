# WekaCert

A minimal full-stack personal document and certificate tracker with:

- PIN-based access control
- Secure-ish local data handling (hashed PIN, token auth)
- Document upload (base64), categorization, expiry/permanent support
- Version history per document
- Search/filter and expiry reminders
- Offline-friendly frontend document list cache

## Run

```bash
npm start
```

Open `http://localhost:3000`.

## Test

```bash
npm test
```
