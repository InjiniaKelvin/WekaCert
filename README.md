# WekaCert

Personal Document & Certificate Tracker is a mobile app concept for Kenyan citizens to securely store and manage important personal documents (IDs, certificates, licenses, property papers, and more). The goal is to provide an encrypted local vault for PDFs/images/scans, organized by category, with support for both expirable and permanent documents. Users can upload documents, tag them, mark expiry dates when relevant, and keep versioned histories with timestamps and notes for renewals. The app emphasizes strong access control (PIN/biometrics), offline-first operation, and fast retrieval, with search and filtering by name, type, and expiry status. It schedules local notifications to remind users before documents expire and offers optional encrypted cloud backup for multi-device recovery. The project follows a Scrum-inspired agile plan with sprints covering secure storage, categorization and expiry tracking, version history, access control, reminders, search/filter UX, and optional cloud sync. The proposed stack centers on Flutter (or Kotlin), encrypted SQLite (SQLCipher), platform key storage, and local notifications. This summary is intended for quick onboarding and reporting, and it aligns with the detailed requirements document in the repository.
