# WekaCert User Manual

## Getting Started
1. Open the app in your browser or install on your device.
2. Register with your email and password.
3. Log in to access your dashboard.

## Uploading Documents
- Click the Upload button.
- Select a file (PDF, image, or any type, up to 50MB).
- Enter document name, category, expiry date (optional).
- Save. The document is encrypted and stored.

## Viewing Documents
- Dashboard shows recent and expiring documents.
- Click a document to view details, version history, and download files.

## Managing Versions
- In document detail, click "Add New Version" to upload a new file.
- All versions are listed with timestamps and notes.

## Expiry Reminders
- Expirable documents trigger reminders before expiry.
- Set reminder threshold in Settings.

## Security
- Enable PIN or biometric access in Settings.
- The current web flow stores uploaded versions through the authenticated backend.
- Mobile-only backup remains optional for supported devices.

## Backup & Restore
- Enable cloud backup in Settings (mobile only).
- Restore documents on a new device by logging in and connecting backup.

## Current Limitation
- Fully offline document access is still a roadmap item rather than the primary app flow.

## Logout
- Use the logout button in the dashboard to clear your session.
